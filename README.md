# HC Tech Infocell - Sistema de Gestão de Assistência Técnica

Sistema completo para gestão de ordens de serviço, orçamentos, clientes, estoque e financeiro para assistência técnica de celulares e notebooks.

## 🚀 Tecnologias

- **Frontend:** React 18 + TypeScript + Vite
- **UI:** shadcn/ui + Tailwind CSS
- **Estado:** Zustand + TanStack Query
- **Backend:** Supabase (PostgreSQL + Auth + Realtime)
- **Deploy:** Cloudflare Pages / Vercel
